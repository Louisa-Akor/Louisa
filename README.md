# Profluent OS — The Undercurrent

A founder-built MVP concept and single-page website. The current prototype is in `index.html` and uses plain HTML, CSS, and JavaScript.

## Progress

- **Version 1:** Created the first landing-page prototype with a feature overview, community mockup, journal mockup, waitlist, and sign-in screens.
- **Version 2:** Added community guidelines, sample reporting and encouragement-letter flows, and clearer journal privacy language. Updated the homepage so prototype interactions are labeled as demos and do not imply that personal data is saved or sent.
- **Learning:** Building the MVP while learning web development with help from Claude AI and GitHub Copilot.

## Current status

This is a front-end demonstration, not a production mental-health or social-network service. The sample feed and profiles are fictional. Account creation, community posts, connection requests, reports, letters, waitlist sign-ups, feedback submission, journal saving, encryption, and AI reflection are not connected to a backend. Do not enter real personal or sensitive information.

Before inviting real users, plan and implement secure authentication and storage, privacy/consent disclosures, moderation and report-response processes, age-appropriate safeguards, accessibility checks, and appropriate crisis-support guidance. Do not claim encryption, anonymity, moderation, or data collection unless those features are implemented and verified.

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required; Google Fonts are loaded from Google Fonts when online.
